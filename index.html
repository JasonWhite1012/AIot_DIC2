CRISP-DM 數據採掘方法論執行全貌 (Methodology)
Phase 1
商業理解
釐清新創獲利預測目標，確立在避免過度配適與多重共線性前提下尋求最佳精簡模型。
Phase 2
資料理解
審查 50 筆新創數據分佈、特徵相關係數矩陣，確認無遺漏值，R&D Spend 相關性最高 (r=0.97)。
Phase 3
資料準備
對 State 實施 One-Hot Encoding，以 California 為基準對照組；80/20 嚴格劃分訓練與測試集。
Phase 4
模型建構
執行 5 大特徵選取法 (LassoCV, RFECV, SFS, ElasticNet, Exhaustive)，評估 k=1..5 漸進組合。
Phase 5
成效評估
以測試集 RMSE 與 R² 為客觀標準，驗證 k=2 為全局最優，k=5 出現雜訊與共線性懲罰。
Phase 6
應用部署
封裝為 GitHub Pages 靜態儀表板與 Flask REST API，提供端到端即時推論與視覺化決策支援。
